# Fit Live Simulator (ShiftAI Sandbox)
Banc d'essai virtuel pour contrôleur de transmission automatique vélo.

- Moteur physique simplifié (250W, pente variable, résistances fixes)
- Serveur async WebSocket + HTTP (accessible mobile)
- Place réservée : `controller/` (algo auto-changement) et `emulator/` (Arduino ESP32)
